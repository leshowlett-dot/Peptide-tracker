# Peptide Tracker

A private, installable web app (PWA) for tracking doses, stock, batches and CoAs, weight and progress.
There is no server: all data stays in your browser's storage on your device.

Open the site, then in Chrome use the menu and choose "Install app" (or "Add to Home screen").

Use Settings, then Export backup before clearing browser data or changing devices.
Medication amounts are estimates, not blood measurements or dosing advice.
